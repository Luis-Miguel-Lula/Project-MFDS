# MFDS Workspace

Aplicação web desenvolvida com React, TypeScript e Vite para apoiar a
organização de projetos, tarefas, ideias e automações.

## Requisitos

- Node.js em versão LTS compatível com as dependências do projeto.
- npm.
- Git.
- Visual Studio Code (recomendado).

## Instalação

Clone o repositório e entre na pasta do projeto:

```bash
git clone URL_DO_REPOSITORIO
cd mfds-web
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço apresentado no terminal.

## Comandos disponíveis

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

## Tecnologias

- React

## Estado atual

Esta é a base inicial do frontend.

O dashboard utiliza dados demonstrativos e interações locais.
Autenticação, persistência, backend, integrações de IA e automações
serão desenvolvidos em etapas posteriores.

## Colaboração

- Desenvolva funcionalidades em branches próprias.

- Não envie credenciais, chaves de API ou arquivos de ambiente com segredos.
- Atualize a documentação quando alterar a forma de executar o projeto.
